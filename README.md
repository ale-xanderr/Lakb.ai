# 🌏 Project Lakb.ai  
### An AI-Powered Travel Discovery and Planning Engine  
**Version:** 1.0  
**Team:** LOCaiT  

---

## 📘 Overview

**Lakb.ai** is an AI-driven travel discovery and planning application designed to help users **discover destinations, activities, and local experiences** based on their **interests, moods, and travel context**.  
By integrating **artificial intelligence** with **Google Places**, **Google Reviews**, and **TripAdvisor APIs**, the system provides **personalized travel recommendations** and **itinerary generation**, creating a smarter, data-driven travel companion for every kind of explorer.

---

## 🎯 Purpose

This repository contains the implementation and documentation for **Project Lakb.ai**, built for the **Application Development (CCCS 106)** course under **Team LOCaiT**.  
The project aims to:
- Utilize **AI-powered personalization** to recommend destinations and itineraries.  
- Integrate **real-world APIs** to provide up-to-date travel data, routes, and reviews.  
- Enhance **local and international tourism engagement** by connecting travelers, locals, and businesses through data-driven insights.  

---

## 🌍 Scope

Lakb.ai serves as a **mobile-based AI recommendation engine** designed for three main user groups:
- **Travellers and Tourists** – Discover new attractions, routes, and itineraries.  
- **Local Residents** – Explore nearby hidden gems and local experiences.  
- **Travel Agencies** – Promote destinations and monitor popularity trends.

By offering real-time and preference-based travel suggestions, Lakb.ai aims to **boost tourism, foster local exploration, and simplify trip planning** through an intuitive AI-powered experience.

---

## 🧠 Core Features

### 🔐 User and Account Management
- Google, Email, or Guest login options.  
- User profiles with editable travel preferences and saved destinations.

### 🧭 AI-Based Recommendation System
- Personalized travel suggestions based on user preferences, location, and travel mood.  
- AI-generated itineraries considering budget, duration, and activity type.

### 📍 Location-Based Search and Maps
- Real-time location search using **Google Maps/Places API**.  
- Visual route and map display with travel time and distance.

### 🏞️ Destination Details and Reviews
- Rich destination pages with photos, descriptions, ratings, and reviews.  
- Integration with **TripAdvisor** and **Google Reviews API**.

### 💾 Favorites and Saved Itineraries
- Save favorite locations and generated itineraries to personal profiles.  
- Optional trip notifications and reminders.

---

## ⚙️ System Architecture

Lakb.ai combines **AI processing**, **Flet UI components**, and **MySQL-based data persistence** into an integrated modular architecture.
